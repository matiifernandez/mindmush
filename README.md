# MindMush

AI-powered mini-games platform built with Rails 7. Create, play, and share HTML5 Canvas games generated by AI.

## Features

- **AI Game Generation** - Create unique mini-games using natural language prompts powered by Groq (LLaMA 3.3 70B)
- **Play & Compete** - Play games, save scores, and climb the leaderboards
- **Social Features** - Vote on games (like/dislike), report inappropriate content, view user profiles
- **Admin Dashboard** - Moderate games and reports, manage content
- **PWA Ready** - Installable as a Progressive Web App

## Tech Stack

- Ruby 3.3.5 / Rails 7.1.6
- PostgreSQL
- Devise (authentication)
- Hotwire (Turbo + Stimulus)
- esbuild + Tailwind CSS 4
- Groq API for AI generation

## Setup

### Requirements

- Ruby 3.3.5
- PostgreSQL
- Node.js & Yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/matiifernandez/mindmush.git
cd mindmush

# Install dependencies
bundle install
yarn install

# Setup database
bin/rails db:create db:migrate db:seed

# Add Groq API key
bin/rails credentials:edit
# Add:
# groq:
#   api_key: your_api_key_here

# Start development server
bin/dev
```

The app will be available at `http://localhost:3000`

### Make a user admin

```bash
bin/rails runner "User.find_by(username: 'your_username').update(admin: true)"
```

## Game Structure

Games are JavaScript objects running on a 400x400 canvas:

```javascript
const game = {
  config: { duration: 30 },
  state: { score: 0, isRunning: false, timeLeft: 30 },
  init(canvas) { /* setup */ },
  start() { /* begin game */ },
  tick() { /* called every second */ },
  handleClick(e) { /* user interaction */ },
  render() { /* draw to canvas */ },
  end() { /* cleanup */ }
};
```
